# Design Principles Synthesis — respeak
_Design-synthesis agent output. Date: 2026-08-31. Inputs: docs/architecture.md; research/synthesis/{config-critique,corpus-expansion,solutions-and-media}.md; research/sources/*.md_

## 1. VERDICT: the two-lane architecture

**Supported — the strongest possible finding: nothing else does this, and every component has mature precedent.** Both landscape passes independently concluded no existing system combines a governed evolving shorthand vocabulary + an always-on multi-register translator + a legibility feedback loop (solutions-and-media.md §1 verdict; landscape-and-media.md:69-73; token-compression-prior-art.md:153). Each pillar is separately proven: the machine lane's economics by the attention-budget/n² argument (anthropic-effective-context-engineering.md, "smallest set of high-signal tokens") and by Agora's frequency-tiered routines (solutions-and-media.md #2); the ratified-lexicon model by a century of codified expert shorthands — Q-codes, ICAO phraseology, brevity codes, TJC ban list (linguistics-of-expert-shorthand.md §5); the translator-as-subagent by the sub-agent architecture pattern where specialists "return condensed summaries, often 1,000–2,000 tokens" in clean contexts (anthropic-effective-context-engineering.md); and the registry-over-prose choice by the harness finding that structured, modification-resistant formats resist agent drift (anthropic-long-running-harnesses.md, feature-list pattern).

**Refined in four ways:**

1. **Ratification alone is not governance.** The draft's append-mostly + legibility floor is necessary but far short of what every surviving codified shorthand converged on: a size cap (Gregg's 181-brief lesson), minimum edit distance between tokens (QD/QOD, IU/IV near-neighbor failures), scheduled re-harmonization (ICAO's own SID/STAR phraseology eroded without it), usage-based retirement (Q-code deprecation), reserved repair metawords, in-band register marking, and readback for high-stakes messages (linguistics-of-expert-shorthand.md §6.3-§6.10; operationalized as the `shorthand.*` block in config-critique.md §1).
2. **The nudge should capture, not suppress.** FAIR 2017 is the ancestor of the legibility nudge, but its move was to reward English and suppress the codewords. Respeak's differentiator is capturing emergent codewords *into* the governed lexicon with the translator as the standing reward channel (token-compression-prior-art.md:111-120; solutions-and-media.md #8). The nudge lives at the ratification boundary — prefer the legible variant of a convention — not as per-message pressure on the swarm.
3. **The lanes lawfully converge at one point.** Audience is an axis orthogonal to mode: tech_level 5 (the `author` profile) is the only place shorthand may appear inline to a human, because jargon is licensed by community co-membership (config-critique.md §5; linguistics-of-expert-shorthand.md:42). Two lanes, but three registers of access: forbidden / expand-first-use / inline.
4. **Injection point confirmed but corrected.** "Surface via CLAUDE.md" is right in spirit, but plugins cannot ship CLAUDE.md content; the mechanism is a generated digest imported by the project CLAUDE.md with user consent, plus hooks (claude-code-integration-surfaces.md §6, §11 — see Q2).

**Contradicted in one way:** the draft implies the lexicon is the drift defense. The research says drift happens *even inside governed systems* and predicts the most capable agents deviate most ("fluency breeds deviation," ICAO — linguistics-of-expert-shorthand.md §6.13). Governance must therefore include active auditing (fresh-decoder sampling, usage-vs-lexicon divergence monitoring), not just an approval gate.

## 2. ANSWERS to the five open questions

### Q1. Milestone auto-narrative: Stop vs SubagentStop vs cron?

**Hooks, not cron — a layered set, all in plugin `hooks/hooks.json`** (claude-code-integration-surfaces.md §3, §11):

- **`Stop` command hook** for main-agent turns: its input carries **`last_assistant_message`** (docs explicitly prefer it over parsing `transcript_path`), so the hook applies a cheap milestone/shorthand-density heuristic and only then acts — either returning `hookSpecificOutput.additionalContext` asking for a one-paragraph narrative in the configured mode (gated on `stop_hook_active` to prevent loops), or piping to `claude --bare -p --agents '<respeak json>'` out-of-band. Use `async` handlers so nothing adds latency to ordinary turns.
- **`SubagentStop` and `TaskCompleted`** for swarm workers and true milestones — `TaskCompleted` is the semantically correct "phase boundary" event the draft's "harness-level cron" was groping for; both cost nothing passively.
- **`MessageDisplay` → `displayContent`** as the zero-context-cost layer: it rewrites what the human *sees* while transcript and model context keep the shorthand original — "the purest 'translate for the human without fighting the optimization' surface" (integration-surfaces §3). Its 10s timeout means script-level lexicon expansion, not a model call.

Cron loses on all counts: no access to `last_assistant_message`, no event alignment with milestones, and a standing external process where hooks give the same behavior in-band.

### Q2. Lexicon injection: CLAUDE.md, settings-referenced file, or a skill?

**CLAUDE.md `@import` of a generated digest, installed by a consented `/respeak:init` — with hooks as the freshness channel** (integration-surfaces §6, §11):

- Render the ratified lexicon to a compact `corpus/lexicon-active.md` digest (<200 lines per the memory-doc guidance) and have the project CLAUDE.md carry one `@corpus/lexicon-active.md` line. Every session — swarm workers included — loads it at start; custom subagents also load CLAUDE.md.
- A plugin **cannot** ship CLAUDE.md content, so the `/respeak:init` user-only skill writes the import with consent. Shipped read-only assets live at `${CLAUDE_PLUGIN_ROOT}`; mutable state (proposals, ratified lexicon) at `${CLAUDE_PLUGIN_DATA}` or project `.claude/respeak/` (integration-surfaces §9's path-bug finding).
- `.claude/rules/*.md` with `paths:` frontmatter gives register scoping the draft lacks: shorthand allowed in `notes/**`, banned in `docs/**` (integration-surfaces §6).
- Because CLAUDE.md edits don't apply mid-session, pair with a `SessionStart`/`FileChanged(corpus/lexicon.yaml)` hook injecting factual `additionalContext` ("The lexicon version is v12") — factual phrasing per the docs' prompt-injection guidance.
- **A skill is the wrong vehicle**: skill content loads only on invocation, persists under the shared 25k/5k compaction budget, and depends on the model choosing to load it — adoption "at emission time" requires session-start presence. The optional shipped output style (`keep-coding-instructions: true`) remains the opt-in maximal lever for native shorthand emission (integration-surfaces §5).

### Q3. Vale compilation from banned-phrases.yaml?

**Yes — it is the designed CI path, and it doubles as the translator's rewrite loop** (style-as-code-tooling.md §9): a `respeak compile` script turns banned-phrases.yaml + replacements.yaml + config budgets into a `styles/Respeak/` Vale package plus a generated `.vale.ini` whose **per-mode output globs** (the `output_glob` fields config-critique.md added to each mode) apply Respeak-Eli5 rules only to eli5 outputs, etc. Run `vale --output=JSON` in CI with `min_alert_level: {ci: error, interactive: warn}`; hand ratio/judgment checks Vale can't do (BLUF-first-sentence, metaphor budget, tone) to a post-processor + LLM-judge; feed the JSON diagnostics back to the translator as a rewrite prompt (Promptless precedent). Human-written docs then get the same voice for free — that is the point of style-as-data. **Precondition:** the corpus schema upgrades from corpus-expansion.md §3 items 9-11 — per-entry `exceptions:`, declared anchor scope (a bare `^` means "file start" under Vale), and density budgets for the common-tier words — otherwise the compile produces false positives that discredit the whole gate.

### Q4. Fidelity check before ratifying a lexicon entry?

**A three-layer gate, on Caveman's "verified savings, not vibes" burden of proof** (caveman-so.md: savings show $0.00 until proven by its 27 graders):

1. **Static sign-quality checks at proposal time** (Galantucci criteria): `min_token_edit_distance: 2` against all existing entries, no collision with common English words or project identifiers, no near-neighbor of a never_compress class — the QD/QOD, IU/IV failure taxonomy (linguistics-of-expert-shorthand.md §5.5, §6.7; config-critique.md §1).
2. **The round-trip test, operationalized as a fresh decoder**: a fresh agent with *no interaction history* must expand samples using only the lexicon entry; if it can't, "the meaning has migrated into memory of usage — re-ground it" (linguistics-of-expert-shorthand.md §6.11, Fay/Garrod partner rotation). This is strictly stronger than a same-agent round-trip, which shared context would trivially pass.
3. **Usage evidence for auto-ratification**: the structured `auto:` gate — N uses, zero translation-fidelity failures, and readback evidence (downstream correct action + verified echo, ICAO's grounding hierarchy) (config-critique.md §2.7; linguistics-of-expert-shorthand.md §6.10). Human ratification remains the default (`ratification: human`); the gate governs only what may even be proposed for fast-track.

### Q5. tech_level 5 raw shorthand: feature or leak?

**Feature — but only as an explicit opt-in profile, never a mode default.** Three grounds: jargon is licensed by community co-membership, and a level-5 reader who ratifies the lexicon *is* a community member with real (not assumed) common ground (linguistics-of-expert-shorthand.md:42; config-critique.md §5); tone-mapping designates level 5 as the only level where shorthand may appear inline, and the `author` profile with `lexicon_access: inline` is "the only profile where the two lanes may converge" (config-critique.md §5); and GibberLink's lesson is that a mode switch is legitimate when announced and decodable — the leak is silent, unmarked convergence, not convergence itself (token-compression-prior-art.md:85; landscape-and-media.md:48). Guardrails that keep it a feature: `register_marker: required` (shorthand use announced in-band, ICS "Interco" pattern), the never_compress classes and reserved metawords stay verbatim even at level 5, and level-5 output still enters the monthly fresh-decoder audit sample so author-profile traffic can't become the drift vector.

## 3. THE PRINCIPLES

1. **Count the reader's effort in the total cost.** Least *collaborative* effort includes the human decoder — a perpetual overhearer who can't read pair-evolved signs — so compression that strands the human violates the very efficiency principle that motivates it (linguistics-of-expert-shorthand.md §6.1, Garrod et al. 2007 Exp. 3).
2. **Compression is inevitable; capture it, don't suppress it.** Alignment/entrainment happens automatically, so convert implicit routinization into recorded, ratified pacts — the anti-FAIR-2017 move: emergent codewords become lexicon proposals, not lint suppressions (linguistics-of-expert-shorthand.md §6.2; token-compression-prior-art.md:111-120).
3. **One governed, versioned dictionary with a scheduled revision cycle.** Every mature shorthand system converged on a single owned registry, and drift happened anyway where re-harmonization wasn't scheduled (linguistics-of-expert-shorthand.md §6.3, SID/STAR erosion).
4. **Load-bearing state is structured and modification-resistant; prose is for logs.** The lexicon follows the harness feature-list pattern — models are less likely to inappropriately change structured files, and "compaction alone is not sufficient" (anthropic-long-running-harnesses.md).
5. **Keep the lexicon small and earn every entry's keep.** Gregg kept 150 WPM after cutting to 181 briefs; cap entries (~150), demand usage evidence, retire cold entries on the Q-code deprecation pattern (linguistics-of-expert-shorthand.md §5.6, §6.8; config-critique.md §1).
6. **Never compress high-surprisal content, and every ban carries its failure story.** Identifiers, numbers-with-units, errors, negations, novel decisions stay verbatim (Piantadosi 2011), in a TJC-format list where each entry records the confusion mode and replacement (linguistics-of-expert-shorthand.md §6.5-§6.6).
7. **The translator proposes, config disposes, the human ratifies — and evolution must stay cheap.** FIPA-ACL "ossified because there was no lightweight evolution process"; separation of powers plus a low-friction amendment path are jointly what its history demands (solutions-and-media.md #5; token-compression-prior-art.md:97).
8. **Prove fidelity before adoption: $0.00 until graded.** Caveman gates every compression behind 27 graders before it counts; a lexicon entry ratifies only after static sign-quality checks, a fresh-decoder round trip, and readback evidence (caveman-so.md; linguistics-of-expert-shorthand.md §6.10-§6.11).
9. **Nudge at the point of emission, never by post-hoc rewriting of the machine lane.** Conventions enter via the session-start lexicon digest and ratification preferences; human-facing correction happens in display (`MessageDisplay`) or in the human lane, leaving swarm context untouched (caveman-so.md design lesson 2; claude-code-integration-surfaces.md §3, §6).
10. **A config field is a behavior or it is deleted.** Bare scalars LLMs can't reliably interpret (warmth: 0.4) get replaced by checkable switches, and constraints become budgets scaled to length, not zero-tolerance bans (config-critique.md §3; style-as-code-tooling.md §9).
11. **Voice is constant; tone varies by profile × mode × context.** Audience (who), form (mode), and reader state (incident/routine) are orthogonal axes — the Mailchimp voice/tone split plus partner-specific-pact evidence that lexicon access keys to *who reads*, not *what form* (style-as-code-tooling.md §5; config-critique.md §5).
12. **Style is data, enforced by the same gate for humans and agents.** The corpus compiles to a Vale package run in CI over both generated narratives and human-written docs, with diagnostics fed back to the translator as rewrite prompts (style-as-code-tooling.md §9 CI path).

## 4. RISKS

1. **Lexicon drift despite ratification.** Meaning migrates from the entry into "memory of usage," and the most fluent agents deviate most, especially under stress (linguistics-of-expert-shorthand.md §6.11, §6.13). *Mitigation:* scheduled re-harmonization (`review_cadence_days: 90`), monthly fresh-decoder audits over a 10-entry sample, retirement after 180 days unused, and monitoring usage-vs-lexicon divergence as a first-class failure condition — plus lint the strongest agents hardest on incident/error paths (config-critique.md §1).
2. **Translator hallucination — confident narratives that misreport swarm state.** The human lane is the human's only window; a wrong BLUF is worse than shorthand. *Mitigation:* translator stays read-only toward swarm state with never_compress content passed verbatim (error text, quotes, numbers survive any rewrite); `facts-before-stories` and `delete-test` checks make the first evidence-bearing sentence a fact; the `UNVERIFIED` reserved metaword fences speculation; readback required before narrating irreversible actions or security findings (config-critique.md §§1,4; linguistics-of-expert-shorthand.md §6.9-§6.10).
3. **The nudge backfires into taxing the swarm** — per-message legibility pressure recreates the "force the swarm to write prose" failure the project exists to avoid. *Mitigation:* the nudge acts only at the ratification boundary (prefer the legible variant of a proposed convention) and in display-only surfaces (`MessageDisplay` rewrites what the human sees while model context keeps the original); machine-lane style constraints are budgets, not bans (caveman-so.md; claude-code-integration-surfaces.md §3; style-as-code-tooling.md §9).
4. **Governance ossification or overhead exceeding savings** — FIPA's death by heavyweight process, or a human ratification queue nobody clears. *Mitigation:* proposals are a free side effect of translation, the 150-entry cap keeps review tractable, and the structured `auto:` gate fast-tracks low-stakes entries that pass fidelity while reserving human ratification for the rest (token-compression-prior-art.md:97; config-critique.md §2.7).
5. **Platform-surface rot.** The integration audit already caught a moved docs domain, a removed `/agents` wizard, deprecated `commands/`, a self-colliding command/skill pair, and cwd-relative path bugs that break on plugin install (claude-code-integration-surfaces.md §0, §9). *Mitigation:* consolidate to one skill + one subagent + plugin hooks, reference runtime names not file paths, keep mutable state in `${CLAUDE_PLUGIN_DATA}`, and run `claude plugin validate` in CI so surface drift fails loudly.
