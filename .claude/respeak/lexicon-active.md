# Respeak ratified shorthand (lexicon v0)

Only these terms may be used as shorthand in agent traffic. Anything else is written out in full. Never compress: error
messages, security findings, user quotes, numbers with units.

| term | expands to | meaning |
|---|---|---|
| `cfg` | configuration | Any respeak configuration value; not general app config. |
| `R1..R7` | research dimension 1-7 | The seven wide-net research dimensions from the 2026-08-31 research run (deai-language, token-compression, linguistics, communication-practices, style-as-code, claude-code-integration, landscape-and-media). |
